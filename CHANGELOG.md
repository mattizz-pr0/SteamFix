# Changelog

Tutte le modifiche rilevanti di **SteamFix Manager** sono documentate in questo file.

## [1.0.4] — 2026-11-06

### Aggiunto
- **⬆ Aggiungi** nella vista Download per i giochi non ancora presenti nel database (prima il pulsante mostrava erroneamente "Aggiorna")
- Licenza **MIT** visibile nell'app: la voce in basso nella sidebar è cliccabile e apre il testo completo della licenza
- README bilingue italiano / inglese
- File `CHANGELOG.md`

### Corretto
- Dopo un'azione nella vista Download il pulsante torna all'etichetta corretta: **🔄 Riscarica** per i giochi già presenti, **⬆ Aggiungi** per quelli nuovi

### Modificato
- Licenza del progetto passata da proprietaria a **MIT** (`LICENSE`, `package.json`, README)
